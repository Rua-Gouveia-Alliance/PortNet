# PortNet

This README provides an overview of the project structure and instructions to install dependencies and run the code.

## Project Structure

All code is written in Python and stored in the `scripts` directory:

* `scripts/symbol_scraper_*.py` — Collects all symbols of an index from the past 3 years.
* `scripts/price_scraper.py` — Collects price information for a list of symbols over a 3-year period.
* `scripts/distances.py` — Calculates normalized log returns and distance matrices using PCC and SCC.
* `scripts/communities.py` — Transforms the fully connected graph into an MST and partitions it using Louvain and Girvan–Newman algorithms.
* `scripts/cooccurence.py` — Computes co-occurrence matrices.
* `scripts/asset_selection.py` — Generates the final portfolios using nine different strategies described in the report.
* `scripts/portfolio_evaluation.py` — Computes returns, Sharpe ratios, and generates evaluation graphs.

The `data` directory stores all intermediate and final data generated by the scripts, including graphs saved in `.gefx` format. These can be visualized with [Gephi](https://gephi.org/).

The `report.pdf` file contains the full project report.

## Dependencies

To run the scripts, you need the following Python dependencies:

* python = 3.12
* yfinance = 0.2.66
* pandas = 2.3.3
* numpy = 2.2.6
* scipy = 1.16.2
* networkx = 3.5
* openpyxl = 3.1.5
* scikit-learn = 1.7.2
* matplotlib = 3.10.6

If you have [Anaconda](https://anaconda.org/) installed, you can set up the environment with:

```bash
conda env create -f environment.yml
```

## Reproducing Results

> [!CAUTION]
> The `symbol_scraper_*.py` and `price_scraper.py` scripts collect data from the past 3 years **relative to the execution date**.
> To ensure reproducibility, we provide the scraped data used in our experiments. If you rerun the scrapers, your results will reflect the **current** date.

All scripts should be executed from the `scripts` directory.

### Partial Reproduction

Some scripts, especially `scripts/cooccurence.py`, may take significant time to run depending on your hardware.
To make reproduction easier, we provide all pre-generated data. You can directly evaluate the portfolios with:

```bash
python portfolio_evaluation.py
```

### Full Reproduction

If you want to rerun the entire pipeline, follow these steps:

1. Compute the distance matrices:

   ```bash
   python distances.py
   ```

2. Compute the co-occurrence matrices and calculate the communities:

   ```bash
   python cooccurence.py
   python communities.py
   ```

3. Generate and evaluate the portfolios:

   ```bash
   python asset_selection.py
   python portfolio_evaluation.py
   ```

## How to Run with the Most Recent Data

If you want to work with the latest market data, start by executing the scraper scripts:

```bash
python symbol_scraper_ftse100.py
python symbol_scraper_sp500.py
python price_scraper.py
```

Then follow the **full reproduction** steps above.
