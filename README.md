# PortNet

This README describes the structure of the project, along with instructions to install the required dependencies and run the code.

## Project Structure

All code is written in Python and located in the `scripts` directory:

- `scripts/symbol_scraper_*.py`: Collects all the symbols of an index from the past 3 years.
- `scripts/price_scraper.py`: Collects price information for a list of symbols over a 3-year period.
- `scripts/distances.py`: Calculates normalized log returns and distance matrices using PCC and SCC.
- `scripts/communities.py`: Transforms the fully connected graph into an MST and partitions it using Louvain and Girvan–Newman algorithms.
- `scripts/cooccurence.py`: Computes the co-occurrence matrices.
- `scripts/asset_selection.py`: Generates the final portfolios using the 9 different strategies described in the report.
- `scripts/portfolio_evaluation.py`: Computes returns, Sharpe ratios, and generates graphs for portfolio evaluation.

The `data` directory stores all intermediate and final data generated by the scripts, including graphs saved in `.gefx` format. These can be visualized with [Gephi](https://gephi.org/).

The `report.pdf` file contains the full project report.

## Dependencies

To run the scripts, the following Python dependencies are required:

- python = 3.12
- yfinance = 0.2.66
- pandas = 2.3.3
- numpy = 2.2.6
- scipy = 1.16.2
- networkx = 3.5
- openpyxl = 3.1.5
- scikit-learn = 1.7.2
- matplotlib = 3.10.6

If you have [Anaconda](https://anaconda.org/) installed, you can easily set up the environment using the provided `scripts/environment.yml` file:

```bash
conda env create -f environment.yml
```

## How to Run

All scripts should be executed from the `scripts` directory.

Since the `symbol_scraper_*.py` and `price_scraper.py` scripts collect data from the past 3 years relative to the execution date, we provide the scraped data used in our experiments so you can reproduce our results. If you choose to re-run the scripts, the results will reflect the current date.

To scrape the data, run:

```bash
python symbol_scraper_ftse100.py
python symbol_scraper_sp500.py
python price_scraper.py
```

To compute the distance matrices, run:

```bash
python distances.py
```

To calculate the communities:

```bash
python communities.py
```

To compute the co-occurrence matrices and recalculate the communities:

```bash
python cooccurence.py
python communities.py
```

Finally, to generate and evaluate the portfolios:

```bash
python asset_selection.py
python portfolio_evaluation.py
```
